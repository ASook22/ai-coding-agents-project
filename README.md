# AI Coding Agents: The Future of Software Development

## Project Overview

This project explores the growing role of AI coding agents in software development. We examine how these tools assist developers, how they differ from traditional AI coding assistants, and the potential benefits and risks of using them.

Our project focuses on a recent development in AI coding agents and considers the following question:

**Are AI coding agents making software developers more productive, or introducing new risks?**
