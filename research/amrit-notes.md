# Amrit's Research Notes

**Project:** AI Coding Agents  
**My part:** Introduction and current event  

## Main points

- **What is an AI coding agent?** An AI tool that can do several steps of a coding task, such as editing files or running code. This goes beyond autocomplete, which mainly suggests code as you type.
- **Current event:** OpenAI announced its Agents API in public beta on September 10, 2026. It helps developers build agents that can use tools and work through tasks.
- **Why it matters:** AI tools are moving from suggesting code to doing more of the work. Developers still need to check the results.
