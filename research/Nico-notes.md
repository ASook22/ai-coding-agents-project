# Main Points

## 1\. What Are AI Coding Agents?

AI coding agents are AI tools that help developers complete programming tasks. Unlike a basic chatbot that mainly suggests code, an agent can inspect project files, edit code, run commands and use the results to improve its work.

## 2\. How Do AI Coding Agents Work?

First, a developer gives the agent a task such as fixing a bug or adding a feature. The agent examines relevant files and instructions to understand the project. It then makes changes, runs available checks and examines the results. If something fails, it may attempt to correct the problem and test again.

## 3\. How Do They Read Code?

An agent reads source files and existing code to understand how a project works. It can look for functions, variables, errors and other parts related to the task.

## 4\. How Do They Write Code?

An agent can create new files or edit existing files. It uses the user's instructions and the surrounding code to make changes that fit the project.

## 5\. How Do They Test Code?

An agent can run automated tests, build commands or other checks available in the project. It can inspect error messages and try to fix problems. Passing tests does not guarantee that the program is completely correct or secure.

## 6\. Example of an AI Coding Agent in Action

GitHub Copilot coding agent can be assigned an issue in a GitHub repository. It can investigate the code, make changes on a separate branch, run available checks and prepare a pull request for a developer to review. The developer can review the changes before deciding whether to merge them.

### Benefits

* Helps with repetitive programming tasks.
* Can help identify and fix bugs.
* Can create features, tests and documentation.
* Can save time on some development tasks.

### Limitations

* Can generate incorrect or insecure code.
* May misunderstand the task.
* Tests may not cover every possible problem.
* Developers still need to review and verify the changes.

## Conclusion

AI coding agents can read, write and test code as part of a programming task. They can help developers work more efficiently but human review is still important.
