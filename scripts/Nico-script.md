# Nico's AI Coding Agents Script

**Section:** How AI Coding Agents Work  
**Estimated speaking time:** 50–60 seconds

## Script

AI coding agents are AI powered tools that can do more than just suggest lines of code. They can take a goal, break it down into smaller steps, examine a project's files, edit code and use tools to complete tasks with less direct input from the developer.

For example, GitHub Copilot agents can help developers investigate problems, make changes to files and run tests to check whether their code works correctly. If something goes wrong, an agent may be able to review the error and try to fix it.

These tools can save developers time and make programming more efficient. However, they are not perfect and can still make mistakes or produce code that does not work as expected. That's why developers need to review the changes and make sure everything is correct.
