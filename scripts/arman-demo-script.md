# AI Coding Agents — Arman's Contribution

**Section:** Demonstration and Implications  
**Presenter:** Arman  
**Estimated speaking time:** 35 seconds

## Demonstration Outline

1. Give an AI coding agent a task: find a bug, fix it, and write a test.
2. Show how the agent can inspect files, edit code, and run tests.
3. Explain why developers must review and verify the changes.

## Script

Imagine asking an AI coding agent to fix a bug in a program. Instead of only suggesting code, the agent can inspect the files, identify the problem, make changes, and run tests to check its work.

For example, coding agents can help developers automate repetitive tasks and work faster. However, their code can still contain mistakes, so developers must review the changes and test the results before using them.

This shows that AI can assist developers, but human judgment remains essential.
